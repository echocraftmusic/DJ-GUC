# DJ GUC Website — Read Before Editing

This build follows the approved mock: black, purple and silver; large hero; era cards; dedicated Twitch emphasis; Instagram second; TikTok third; no Facebook.

## Do not break
- Keep `index.html`, `css/`, `js/`, `images/` at the project root.
- Do not rename image files unless every matching path in `index.html` is updated.
- Do not remove the mobile rules in `css/responsive.css`.
- Twitch must remain the primary social call-to-action.
- Do not duplicate photos elsewhere on the page.

## Still needed before public launch
1. DJ GUC’s booking email or selected form service.
2. Final biography, if he wants wording beyond the working copy.
3. Theme-song audio file. Put an optimized MP3 in `/audio/` and connect it in `index.html`/`js/main.js`.
4. Optional testimonials and crowd photos.

## Image policy
All production images are WebP. Keep original PNG/JPEG files in a private archive, not in the live GitHub project.

### Logo protection
The live website uses `images/dj-guc-logo-silver.webp`, a transparent, optimized website edition created from the original PNG. Keep `images/dj-guc-logo-master.png` as the untouched source. Do not run the website logo through a converter that removes transparency or adds a black background.
